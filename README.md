# 인플루언서 발굴 프로그램 (신규, 바이어 프로그램과 별도)

## 지금 버전: v0.2
- 화면에서 후보를 직접 추가·수정·삭제할 수 있습니다.
- CSV로 여러 건을 한 번에 등록할 수 있습니다 (v0.1 형식의 옛 컬럼명도 인식함).
- "샘플로 초기화" 버튼으로 언제든 원래 샘플 5건으로 되돌릴 수 있습니다.
- 데이터는 data/influencers.csv 에 저장됩니다.

## 중요: 무료 배포(Render Free)에서 데이터가 사라질 수 있음
Render 무료 요금제는 15분 동안 접속이 없으면 서버가 잠들고, 다시 깨어나거나
새로 배포할 때 로컬 파일 변경 내용이 초기화됩니다. 즉 화면에서 추가·수정한
후보가 시간이 지나면 사라지고 다시 샘플 5건으로 돌아갈 수 있습니다.
지금 단계(테스트)는 문제없지만, 실제로 계속 써야 하는 단계가 되면 진짜
데이터베이스(Render Postgres 등)로 옮겨야 합니다. 다음 단계 후보로 남겨둡니다.

## 로컬에서 실행하기
```
pip install -r requirements.txt
python app.py
```
브라우저에서 http://localhost:5000 열기

## 폴더 구조
- app.py                        : 서버 코드 (후보 추가/수정/삭제/초기화 API 포함)
- static/index.html             : 화면
- data/influencers_seed.csv     : "샘플로 초기화"에 쓰이는 원본 샘플 5건
- data/influencers.csv          : 실제 사용 데이터 (서버가 자동으로 만듦, 깃에는 올리지 않음)
