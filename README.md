# 인플루언서 발굴 프로그램 (신규, 바이어 프로그램과 별도)

## 지금 버전: v0.1 (뼈대)
- 화면과 서버를 연결하는 최소 구조만 있습니다.
- 후보 데이터는 아직 샘플(가상)입니다.
- 실제 인스타그램 API 연결은 다음 단계입니다.

## 로컬에서 실행하기
```
pip install -r requirements.txt
python app.py
```
브라우저에서 http://localhost:5000 열기

## 폴더 구조
- app.py           : 서버 코드
- static/           : 화면 파일(HTML)
- data/             : 후보 데이터(csv)
